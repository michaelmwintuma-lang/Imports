# Site Images Directory (`public/images/`)

Upload all your custom website images (logos, product photos, hero slides, farm pictures, certificates, etc.) into this directory:

`c:\Users\USER\OneDrive\Desktop\Imports\public\images\`

---

## 📁 How to Reference Images in Code or Content:

Any image placed in `public/images/` can be accessed directly in your React code using the root path `/images/<your-file-name>`:

### Examples:
- **Hero Slide 1**: `/images/hero-slide-1.jpg`
- **Company Logo**: `/images/logo.png`
- **Plantain Flour**: `/images/plantain-flour.jpg`
- **Cassava Starch**: `/images/cassava-starch.jpg`
- **Cocoa Beans**: `/images/cocoa-beans.jpg`

---

## 📸 Recommended Image Formats & Sizes:
- **Formats**: `.jpg`, `.png`, `.webp`, `.svg`
- **Hero Slider Images**: 1920x1080 resolution (or 16:9 aspect ratio)
- **Product Thumbnails**: 800x800 resolution (1:1 square ratio)
